📁 直接保存到项目

点击连接并选择博客根目录（包含 data/ 和 images/ 的目录）。连接后：

  • 文章和小记直接写入 data/articles.json、data/notes.json
  • 上传图片直接保存到 images/uploads/年/月/日/，不再转 Base64
  • 保存文章或小记时自动同步，无需复制粘贴

浏览器：请使用最新版 Chrome 或 Edge。旧 Base64 图片会在写入项目时自动迁移。

📤 备用下载

如果浏览器不支持目录写入，仍可下载完整 JSON 文件后覆盖项目中的同名文件。

📥 数据导入

可以从已有的 JSON 文件导入数据，覆盖当前编辑的内容。
